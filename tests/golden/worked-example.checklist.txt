# Checklist — worked-example

Run from the repo root. Every box is something you can see for yourself.

- [ ] `python3 <SKILL>/check_scope.py examples/worked-example.yaml`
      → `0 violation(s)`. Checks the scope, the forbidden paths and the tests policy
        against the real diff. Independent of anything the agent reported.

- [ ] `python3 -m src.report` → exit 0, output identical to the baseline digest
      → was green; must still be green
- [ ] `python3 -m unittest -q tests.test_cart` → exit 0
      → was green; must still be green
- [ ] `python3 -m unittest -q tests.test_legacy` → exit 1 — the one known failure, unchanged
      → must stay exactly as measured (exit 1, 0 line(s) stdout, 0.3s) — do not 'fix' it. A different result is a regression even if it looks better
